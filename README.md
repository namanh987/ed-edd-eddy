# Ed, Edd n Eddy

**Ed, Edd n Eddy** is an AI-powered English learning platform that helps learners improve their English through natural text conversations with three unique AI companions:

* **Ed** – an encouraging, beginner-friendly, confidence-building character through supportive feedback.
* **Edd** – a scholar who explains grammar, vocabulary, n language concepts in detail.
* **Eddy** – a street-smart companion who teaches practical, everyday English n natural expressions.

The name is a tribute to the classic cartoon *Ed, Edd n Eddy*, each character has a similar temper to their animated counterparts.

Due to copyright, they do not share the exact same characteristics n personalities as the animated version of the characters, but they do share similar characteristics.

The backend is built with **FastAPI**, **SQLAlchemy** n **SQLite** for local development, using **Google Gemini** to generate AI responses with real-time streaming. The **Next.js** frontend provides a personalized n conversational learning experience.

This project is dedicated to my English-speaking friend n tutor **Edward** (no offense to Cres n Manas), who inspired both the project's idea n it's name.
